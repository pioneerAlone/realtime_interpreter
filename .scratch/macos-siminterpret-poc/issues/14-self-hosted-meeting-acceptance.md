# 自开会议端到端验收（R3 + R4）

Labels: wayfinder:task

Status: open
Type: task
Blocked by: 11, 13

## Question

在本机自开一个 Zoom（或两个 macOS 账号互开）会议，**端到端验证 PoC**：

**验收步骤**：
1. **场景 A · 单机双账号自开会议**（最简单）：
   - 同一台 Mac 上登录两个 Zoom 账号（用户账号 + 副账号 / 临时账号）
   - 用户账号进入会议作为"中文用户"
   - 副账号进入会议作为"英文客户"
   - **R3 验证**：用户说中文 → 副账号听到英文（音色像用户）→ 副账号在会议里回应
   - **R4 验证**：副账号说英文 → 用户账号看到中英双语字幕
   - 截图 / 录屏保存
2. **场景 B · 真实会议压力测**（可选，如果场景 A 通过）：
   - 请一个真朋友 / 同事用 macOS + Zoom 当客户
   - 跑一个 5 分钟的"伪会议"（不需要真有内容，可闲聊）
   - 验证反馈环 / 延迟 / 字幕 / 音色在真实多人下的稳定性
3. **多会议场景压力**（可选）：
   - 跑 30 分钟 / 60 分钟连续会议
   - 看延迟 / 音色是否漂移 / 字幕是否漏字 / 客户端是否断连

**验收 checklist**：
- [ ] R3 出方向：中文 → 客户听到英文（音色像用户）
- [ ] R4 入方向：英文 → 用户看到中英双语字幕
- [ ] 无反馈环（中文 → 翻译 → 中文 → 翻译 的死循环没出现）
- [ ] 无串扰（用户麦克风不会采到翻译输出）
- [ ] 字幕与英文语音大致对齐（时差 < 1 秒）
- [ ] 戴耳机场景下体验流畅（不需要戴耳机 = 二期）
- [ ] 30 分钟连续运行稳定

**deliverable**：
- 验收 checklist 全过 / 部分过
- 截图 / 录屏
- 「实测 vs PDF §3 口径的对比」
- 「进入 v1 map 的下一批 ticket 候选清单」（基于验收过程中暴露的新问题）

**前置依赖**：
- T11（CLI 字幕格式已定）
- T13（BlackHole 音频环路验收已通过——本票是它的"接上会议软件"延伸）
