## Question

火山引擎（volcengine.com）账号注册到 PoC 可用的最小链路：

1. **个人注册路径**：注册是否需要实名？是否要求企业资质？还是个人身份证即可？海外手机号能否注册？
2. **应用创建**：登录后如何创建"应用"拿到 `APP_ID` + `APP_KEY` / `TOKEN`？同传 2.0 / 声音复刻 2.0 / 实时字幕分别是独立应用还是同一应用下开通多个能力？
3. **免费试用**：新账号是否有免费试用金 / 免费调用额度？试用金有效期多长？试用阶段是否限速（QPS / 并发）？试用阶段是否限制某些高级能力（如声音复刻）？
4. **实名 → 充值链路**：实名之后是否必须先充值才能调用？最低充值金额？是否支持支付宝 / 微信 / 信用卡（海外卡）？
5. **从注册到能发起第一次 S2S 调用**，按照官方文档的步骤，实际耗时通常在多久？（文档可能写"立即"，但实战可能有 1-3 天延迟）
6. **2026-09 是否有变化**：相比 2025 的流程，2026 年是否新增了资质要求、限速调整、价格调整、或者能力下线？

需要查证公开文档 + 控制台可访问页面（不需要登录的都能查）。

## Answer

Findings: `.scratch/macos-siminterpret-poc/research/02-volcengine-account-application.md`

个人 +86 手机号 + 大陆身份证即可注册+实名 (海外证件公开文档无路径); 同传 2.0 走火山方舟 API Key、声音复刻 2.0 走豆包语音 APP ID + Access Token, 两个独立应用; 控制台"试用"即赠免费额度+后付费无需先充值, 实名到首次调用约 30 分钟; 2026 未新增资质要求/能力下线. 18 primary sources cited.
