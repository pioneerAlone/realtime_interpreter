## Goal

Land the macOS build pipeline that produces a `.app` bundle + unsigned DMG for `aarch64-apple-darwin` and `x86_64-apple-darwin`, runs `codesign --force --deep --sign - realtime_interpreter.app` for ad-hoc self-sign, and ships on GitHub Releases — so that v0 can be downloaded and installed by an end-user following the README's two-step first-open instructions.

## Acceptance criteria

- **D22 — Unsigned + ad-hoc self-sign + two-step first-open flow**: `pnpm tauri build` (or the `scripts/build.sh` wrapper) produces (a) `.app` bundle for `aarch64-apple-darwin` and `x86_64-apple-darwin`; (b) ad-hoc self-signed via `codesign --force --deep --sign - realtime_interpreter.app` so users do NOT see "unidentified developer"; (c) unsigned DMG with README first-open instructions.
- **Two-step first-open flow** documented in README (per D22 + `06-deliverables.md` §2.1): users must EITHER run `xattr -dr com.apple.quarantine /Applications/realtime_interpreter.app` after copying to `/Applications/`, OR right-click the `.app` → Open → click "Open" in the Gatekeeper dialog the first time. Subsequent opens are unrestricted.
- **Bundle ID**: `com.pioneeralone.realtime-interpreter` (placeholder per `06-deliverables.md` §1.1; confirm before shipping).
- **GitHub Releases**: source tarball attached; tag scheme `v0.X.Y` (semver) + `v0.X.Y-tauri` (artifact tag) per `06-deliverables.md` §6 [REVIEW] #3.
- **License clarity**: MIT for app code, Apache-2.0 for vendored Doppelvoice `.proto` (per `06-deliverables.md` §1.3).

## Implementation notes

- **Modules / scripts to be built**: `scripts/build.sh` (orchestrates `pnpm tauri build` + `codesign` + `hdiutil` for DMG); `scripts/notarize.sh` placeholder (no-op at v0; called by `build.sh` with a flag for future v0.x when real signing lands); `tauri.conf.json` finalized (bundle identifier, version); README updated with two-step first-open flow.
- **Ad-hoc self-sign** (per `06-deliverables.md` §1.1 + D22): `codesign --force --deep --sign - realtime_interpreter.app` — the `-` means ad-hoc identity (no Developer ID). After this command, Gatekeeper will still flag the app as quarantined on first open (because it's not notarized), but users will not see the worse "unidentified developer" message that comes from a totally unsigned app.
- **DMG creation**: `hdiutil create -volname "Realtime Interpreter" -srcfolder realtime_interpreter.app -ov -format UDZO realtime_interpreter-v0.X.Y-{arch}.dmg` produces a compressed read-only DMG. Place under `dist/` for upload to GitHub Releases.
- **Two-step first-open flow** (CRITICAL — both options must be in the README; users will hit Gatekeeper):
  - **Option A (recommended for command-line users)**: after copying the `.app` to `/Applications/`, run `xattr -dr com.apple.quarantine /Applications/realtime_interpreter.app`. This removes the quarantine attribute that triggers Gatekeeper. Subsequent opens are unrestricted.
  - **Option B (recommended for GUI users)**: right-click the `.app` → Open → click "Open" in the Gatekeeper dialog. The first open prompts the dialog; subsequent opens are unrestricted because the user explicitly approved.
- **GitHub Release workflow**: `.github/workflows/release.yml` (or documented manual step) on tag push `v*` runs `scripts/build.sh`, uploads `.app` + `.dmg` + `Source code (tar.gz)` to the release. The source tarball is generated by `git archive --format=tar.gz --prefix=realtime_interpreter-$VERSION/ -o dist/realtime_interpreter-$VERSION.tar.gz $TAG`.
- **What this ticket does NOT do** (per D22 + `06-deliverables.md` §6 [REVIEW] #1): real Developer-ID signing + Apple notarization is **deferred to a v0.x release** that budgets the Apple Developer Program enrollment fee. v0 is intentionally unsigned + ad-hoc signed + two-step first-open.
- **Reference decisions**: D6 (Open-Less patterns only — no code from `openless-all/app/src-tauri/src/`), D22 (no Apple Developer Program at v0).
- **Spec cross-refs**: `06-deliverables.md` §1 (macOS `.app` bundle + DMG installer + source tarball) + §2.1 (README first-open instructions, BlackHole install, 4-device wiring, API key from 语音控制台, pre-flight check) + §6 [REVIEW] #1 (D22 lock — unsigned + ad-hoc sign + two-step); `01-architecture.md` §10 (Open-Less borrowing checklist); `00-overview.md` §4.4 (macOS-first platform decision).

## Test plan

Single acceptance seam. Verified by:
- Build smoke: `bash scripts/build.sh` produces both `aarch64-apple-darwin` and `x86_64-apple-darwin` `.app` bundles and DMGs under `dist/`.
- Code-sign verify: `codesign -dv realtime_interpreter.app` shows ad-hoc signature (`Signature=adhoc`) and bundle ID `com.pioneeralone.realtime-interpreter`.
- DMG mount smoke: `hdiutil attach dist/realtime_interpreter-v0.X.Y-aarch64.dmg` mounts the DMG; `cp -R` of the `.app` to `/Applications/` succeeds.
- First-open smoke (manual, on a fresh macOS machine or VM):
  - Copy `.app` to `/Applications/`. Try to open via Finder → Gatekeeper dialog appears.
  - Test Option A: run `xattr -dr com.apple.quarantine /Applications/realtime_interpreter.app` → open via Finder → no Gatekeeper dialog.
  - Test Option B (the previously-quarantined copy): right-click → Open → click "Open" in the dialog → app launches; subsequent opens are unrestricted.
- Self-meeting test (ticket #12) runs against the built `.app` and passes (verifies the bundled binary behaves identically to `cargo run` from source).
